Anotações:

Flex Box 1

Eu vi o básico, colocar display flex no elemento pai e colocar flex auto nos elementos filhos faz com que eles se adaptem ao tamanho da caixa, mas sem mudar de posição:

        
          .pai {
            display: flex;
          }

          .filho {
            flex: auto;
          }

Com isso, conforme a tela aumenta e diminui o tamnho dos filhos mudam para conter todos na mesma linha.

O exemplo está no exercício 1 de flex box.

Flex Direction

Ele altera como os itens estarão distribuidos.

        
            .pai {
              flex-direction: row; 
              (configuração padrão)
            }

Os elementos serão distribuídos da esquerda para a direita.

        
          .pai {
            flex-direction: row-reverse;
          }

Agora os elementos estariam distribuídos da direita para a esquerda.

        
          .pai {
            flex-direction: column;
          }

Vai virar uma coluna vertical de cima pra baixo.

        
          .pai {
            flex-direction: column-reverse;
          }

Distribui os elementos de baixo pra cima.

De flex direction é só isso, o exercício dele é o link flex direction, sem erro!!!

Eixos

Vamos considerar primeiro um eixo na fex-direction: row, que é a configuração padrão. Vamos dar exemplo em todas as 4.

Flex Direction: row

Na flex-direction: row o eixo criado é o main-axis, ou eixo principal,que tem dois pontos, o main start (ou main inicial) e o main end (ou main final).

O outro eixo criado nesse caso é o cross-axis,(eixo transversal) que vem de cima pra baixo, ele também gera dois pontos, o cross-start e o cross-end, que seguem a mesma lógica do main start e o main end.

Sabendo desses nomes agora vamos dar o exemplo nos outros flex-direction.

Flex Direction: row-reverse

A diferença dele para o row é que o eixo horizontal vai da direita para a esquerda (main-axis), o cross-axis fica a mesma coisa.

Flex Direction: column

Agora a coisa complica um pouquinho.

Lembra que o main-axis era pra linha e o cross-axis pra coluna? Bom agora o papel deles inverteu, o main-axis aponta as colunas(vertical) e o cross-axis as linhas(horizontal).

O main-axis nesse caso vai de cima pra baixo, e o cross-axis vai da esquerda pra direita.

Flex Direction: column-reverse

Desse caso para o column normal o que muda é que o main-axis do column é de cima pra baixo, o do column-reverse é de baixo pra cima.

Flex Wrap

O valor padrão dessa propriedade é:

        
          .pai {
            flex-wrap: nowrap;
          }

Isso significa "não quebre", o que significa que esse propriedade define quando o conteúdo vai quebrar a linha (ir pra linha de baixo).

Nesse caso não vai nunca, o conteúdo só vai ficar diminuindo até não dar mais pra caber (isso se você tiver flex:auto, o que é recomendado).

Agora se a configuração for essa:

      
          .pai {
            flex-wrap: wrap;
          }

Quando o espaço do eixo main-axis acabar o espaço, o conteúdo vai quebrar no sentido do eixo cross-axis, é meio confuso mas na prática é bem simples.

Também tem esse aqui:

      
        .pai {
          flex-wrap: wrap-reverse;
        }

Ele faz a mesma coisa do wrap só que por exemplo, se fosse quebrar e ir pra esquerda em baixo, ele quebra e vai pra esquerda em cima dos outros elementos, ele vai na direção contrária ao cross-axis.

Justify Content

Esse cara alinha o conteúdo em relação ao main-axis.

Exemplos de valores:

        
          .pai {
            flex-flow:row nowrap;
            justify-content: flex-start;
          }

Isso faz o item com tal propriedade colar no main start da sua flex-box. Aqui, se tiver espaço sobrando vai ser jogado pro lado do main end.

        
          .pai {
            flex-flow:row nowrap;
            justify-content: flex-end;
          }

Já aqui, o item vai colar no main end, e o espaço sobrando sempre vai ficar pro lado do main start.

        
          .pai {
            flex-flow:row nowrap;
            justify-content: center;
          }

Aqui os itens serão alinhados no meio do main-axis, se sobrar espaço, o espaço será dividido entre o main start e o main end.

        
          .pai {
            flex-flow:row nowrap;
            justify-content: space-between;
          }

Nesse caso, o primeiro e o último item estarão respectivamente colado no main start e colado no main end, e os outros itens serão distribuídos igualmente.

        
          .pai {
            flex-flow:row nowrap;
            justify-content: space-evenly;
          }

Todos os espaços dentro da flex box terão o mesmo tamanho, entre um bloco e outro, entre o main start e o primeiro item e entre o último item e o main end.

        
          .pai {
            flex-flow:row nowrap;
            justify-content: space-around;
          }

Esse aqui pega a quantidade de intens dentro do pai, divide pelo espaço disponível e centraliza cada um dentro de cada "divisão de espaço".

Align itens

O justify content alinha de acordo com o main-axis, o align-itens alinha de acordo com o cross-axis (alinhamento transversal).

        
          .pai {
            flex-flow:row nowrap;
            align-itens: stretch;
             (valor padrão)
          }

Significa esticar, ou seja, os itens irão ocupar o cross-axis do cross start até o cross end.

        
           .pai {
            flex-flow:row nowrap;
            align-itens: flex-start;
             ou flex-end; ou center;
           }

Eles seguem a mesma lógica que a gente viu no justify content, um alinha no cross start, o outro no cross end e o center alinha no centro, não tem erro.

Align Content

Essa propriedade alinha os elementos no eixo transversal (cross-axis) quando eles estão empacotados.

Esse aqui vai ser complicado de explicar então vou trabalhar com exemplos:

        
          .pai {
            flex-flow: row wrap;
            align-content: stretch;
             (valor padrão)
          }

Primeiramente, oque essa propriedade faz? ela decide o que vai acontecer com os espaços em branco da flex-box.

Por exemplo, vamos supor que temos três conteúdos dentro de uma flex-box e ela quebra, o align content vai decidir para onde vai o conteúdo que quebrou a caixa baseado em quanto espaço ainda tem disponível no eixo cross-axis.

No caso do stretch, o computador divide o espaço disponível em 2 linhas de tamanho igual no eixo cross-axis, e expande ou diminui o tamanho dos itens para ocupar exatamente o tamanho do eixo transversal da sua linha.

Isso é bem confuso, então recomendo praticar.

        
           .pai {
            flex-flow: row wrap;
            align-content: flex-start;
          }

Esse aqui é bem mais simples.

Nesse caso, quando um elemento quebrar a caixa o align content vai puxar ele para perto do cross-start, e o resto do espaço fica todo pro cross-end.

        
           .pai {
            flex-flow: row wrap;
            align-content: flex-end;
          }

Aqui ele puxa todos os elementos para o cross-end, não importa se foi o que quebrou, nem qual linha o elemento está, ele vai para perto do cross-end.

        
           .pai {
            flex-flow: row wrap;
            align-content: center;
          }

Aqui é simples, ele vai dividir o espaço sobrando em 2 partes e vai deixar os itens no centro do cross-axis.

        
           .pai {
            flex-flow: row wrap;
            align-content: space-between;
          }

Aqui ele vai colocar os primeiros elementos próximos ao cross-start e os últimos elementos próximos ao cross-end, o espaço sobrando no meio ele vai dividir entre os elementos que virão à seguir.

Lembrando que tudo isso vale para os itens empacotados no main-axis.

        
           .pai {
            flex-flow: row wrap;
            align-content: space-evenly;
          }

Ele divide os espaços entre os empacotamentos igualmente, é bem simples e no meu ver é o melhor.

        
           .pai {
            flex-flow: row wrap;
            align-content: space-around;
          }

Esse aqui divide a área disponível pelo número de empacotamentos e coloca os empacotamentos no centro dessas divisões.

Flex Itens:

Order

Isso não é uma tag, é o nome dado aos itens que recebem características do display flex.

Até agora só vimos o elemento pai receber essas características. Agora serão os elementos filhos.

          
            .filho {
              order: 0;
               (valor padrão)
            }

Todo item dentro de uma flex box por padrão tem essa característica.

Basicamente, os números com o menor valor nessa propriedade são os primeiros a serem exibidos no main-axis.

Por exemplo, se tiver um número com order: 3 e outro com order: -9999; o primeiro a ser exibido vai ser o order: -9999;

Align Self

Ele tem 5 valores, vou explicar rapidinho porque os valores são os mesmos que a gente viu anteriormente.

          
            .filho {
              align-self: auto;
            }

O que essa propriedade faz é exatamente o que a align itens, só que para um único elemento filho.

Nesse caso o elemento herda o align itens e o align content do pai só para ele.

          
            .filho {
              align-self: flex-start;
            }

            ou

            .filho {
              align-self: flex-end;
            }

            ou

            .filho {
              align-self: center;
            }

            ou

            .filho {
              align-self: stretch;
            }

Eu fiz desse jeito porque nós já conhecemos essas características vindo do Align itens, se estiver com dúvida leia o que cada uma faz lá.

Resumindo, ele vai alinhar o item de acordo com o cross-axis.

Flex Basis

Define o "tamanho do elemento".

          
            .filho {
             flex-basis: auto;
             (valor padrão)
            }

Nesse caso o tamanho do item aumenta de acordo com o tamanho do conteúdo.

          
            .filho {
              flex-basis: 200px;
            }

Eu sei que o width pode fazer a mesma coisa, mas tem um porém.

Enquanto tiver espaço as caixas ou a caixa vai ter 200px, mas se não for possível, as caixas vão diminuir de tamanho gradualmente e igualmente.

Shrink & Grow

Essas propriedades ajudam a definir o tamanho do elemento individualmente.

É como perguntar para o elemento pai, "pode encolher? pode aumenter?".

          
            .pai {
              flex-flow: row nowrap;
            }

            .filho {
              flex-basis: 150px;
              flex-shrink: 1;
              flex-grow: 0;
              (valor padrão)
            }

Esses valores "1 e 0" é como dizer pode e não pode para essas propriedades.

Colocar "1" significa pode, ou seja, por padrão, quando necessário os itens vão encolher porque o valor padrão é 1.

Já se colocar "0" é como dizer que não pode, ou seja, os itens não vão crescer por padrão.

Quando eu digo crescer, eu digo que se for possível crescer, cresça, agora na hora de diminuir eu digo, se for necessário, diminua.

Então se você quiser que os elementos sejam totalmente elásticas você vai optar por essas configurações:

          
            .pai {
              flex-flow: row nowrap;
            }

            .filho {
              flex-basis: 150px;
              flex-shrink: 1;
              flex-grow: 1;
            }

Assim, quando o conteiner diminuir eles diminuem junto, quando o conteiner crescer, eles crescem junto.

Um adendo aqui, eu descobri na prática agora que essas propriedades não funcionam direito em imagens.

Acho que é por conta de elas já terem um tamanho definido de fábrica, então no exer8 eu usei width no lugar do flex-basis e no exer9 eu não usei imagens.

Outros Valores

Agora fica um pouco mais complicado, recomendo usar essas propriedades fora de conteúdos de mídia, se não você vai perder muitos fios de cabelo.

          
            .pai {
              flex-flow: row nowrap;
            }

            .filho1 {
              flex-basis: 150px;
              flex-shrink: 1;
              flex-grow: 1;
            }

            .filho2 {
              flex-basis: 150px;
              flex-shrink: 0;
              flex-grow: 0;
            }

            .filho3 {
              flex-basis: 150px;
              flex-shrink: 2;
              flex-grow: 2;
            }

Vamos por partes, o que significa o 2? Já vimos que o 0 significa não pode, e o 1 significa pode, eu coloquei entre aspas porque qualquer número diferente de zero está liberado para executar a ação.

O número que vem depois indica quanto ele vai crescer comparado aos outros que também vão (ou diminuir).

No caso o filho 1 está liberado para crescer ou diminuir normalmente, o filho 2 não pode crescer nem diminuir, e o filho 3 pode crescer e diminuir o dobro do filho 1.

Mas isso não acontece porque o grow ou o shrink dele é 2, é porque o número dele é o dobro do número do outro, se o filho 1 tivesse grow 4 e o filho 3 tivesse grow 8, o filho 3 ainda cresceria o dobro do filho 1.

É bem complicado, mas eu acho que deu pra entender ;).

Flex (short - hand)

É uma shorthand para flex basis, grow e shrink.

          
            Sem shorthand:

            .filho {
              flex-grow: 0;
              flex-shrink: 1;
              flex-basis: 150px;
            }

            Com shorthand:

            .filho {
              flex: 0 1 150px;
            }

Acho que deu pra entender, a primeira propriedade é o grow, a segunda é o shrink e a terceira é o basis.

Claro que tem mais coisas, se não eu não criaria um tópico só pra isso.

          
            .filho {
              flex-grow: 0;
              flex-shrink: 1;
              flex-basis: auto;
            }

            É o mesmo que colocar:

            .filho {
              flex: initial;
            }

Essas são as configurações padrões.

          
            .filho {
              flex-grow: 0;
              flex-shrink: 0;
              flex-basis: auto;
            }

            É o mesmo que colocar:

            .filho {
              flex: none;
            }

Essa é a configuração menos flexível possível, o tamanho do elemento vai depender do tamanho do conteúdo e não vai se adaptar ao tamanho do pai.

          
            .filho {
              flex-grow: 1;
              flex-shrink: 1;
              flex-basis: auto;
            }

            É o mesmo que colocar:

            .filho {
              flex: auto;
            }

Esse valor é o contrário do flex: none, esse é o mais flexível possível, ele se adapta a qualquer situação.

          
            .filho {
              flex-grow: 3;
              flex-shrink: 1;
              flex-basis: auto;
            }

            É o mesmo que colocar:

            .filho {
              flex: 3;
            }

Colocar flex: 3 ou flex: 9, ou flex: 9e50000 são todas configurações apenas do flex grow, as outras configurações ficam com seus valores padrões.

De flex-box é isso!!!

Isso foi toda a parte teórica de flex box, agora vamos trabalhar a parte prática e logo depois o grid layout.

GRID LAYOUT

O que é?

O grid layout é um conteiner pai com uma grade de tamanho determinado pelo dev. Os buraquinhos na grade são chamados de grid itens, ou seja, o pai é o conteiner que define a grade e os filhos são os grid itens.

Quando temos uma linha reta que vai de uma borda até a outra, tanto vertical como horizontal, chamamos isso de grid track.

Quando temos uma grid track na horizontal chamamos de row track, já na vertical chamamos de column track.

Chamamos de grid lines, as linhas que delimitam as colunas, elas são diferentes dos row tracks. Podemos numerar essas grid lines, começando do 1 e indo para o infinito e além.

As linhas horizontais também são chamadas de grid lines, só que elas delimitam as tracks de linhas.

Se contarmos da última linha até a primeira começamos em -1, se contarmos da primeira linha até a última, começamos em 1.

Se eu escrever que uma linha vai da grid line 2 vertical até a -2 vertical, é o mesmo que dizer que a área começa na segunda linha vertical e termina na penúltima vertical.

Chamamos de grid area quando temos grid itens conectados em duas dimensões, vertical e horizontal. Um exemplo é se eu dissese pra criar uma caixa da linha vertical e horizontal 2 até a linha vertical e horizontal -3 eu estaria criando uma grid area.

Chamamos de grid gap o espaçamento de um grid item para o outro, é possível configurá-los individualmente. Isso não muda o tamanho dos grid itens.

Propriedades principais

O principal sem dúvidas é o:

          
            .pai {
              display: grid;
            }

Sem ele as outras não funcionam.

Mais duas importantes aqui:

          
            .pai {
              display: grid;
              grid-template-columns: #;
              grid-template-rows: #;
            }

Ele define quantas linhas e quantas colunas vão ter o grid.

          
            .pai {
              display: grid;
              grid-gap: #;
            }

Define a distancia entre os grid-itens.

Para criar um grid layout basta colocar a propriedade display: grid em um elemento pai que todos os elementos dentro dele serão grid itens.

Align & Justify

Um macete aqui pra lembrar.

Quando falamos de align no grid, sempre devemos lembrar que se refere ao alinhamento vertical.

Já quando falamos justify, nos referimos ao alinhamento horizontal.

Trabalharemos as tags à seguir neste tópico:

align-itens

justify-itens

align-content

justify-content

Vamos falar primeiro sobre o align-itens.

Ele alinha o item verticalmente deentro do seu grid.

O valor padrão dessa propriedade é o stretch, que estica o item de uma linha horizontal até a outra.

          
            .pai {
              display: grid;
              grid-template-columns: auto;
              grid-template-rows: 100px;
              align-itens: stretch;
            }

Nesse caso o item vai cobrir os 100px.

          
            .pai {
              display: grid;
              grid-template-columns: auto;
              grid-template-rows: 100px;
              align-itens: start;
            }

Auto explicativo, ele alinha todos os itens no início do grid, lembrando, o alinhamento é vertical.

          
            .pai {
              display: grid;
              grid-template-columns: auto;
              grid-template-rows: 100px;
              align-itens: end;
            }

Esse alinha no final do grid.

          
            .pai {
              display: grid;
              grid-template-columns: auto;
              grid-template-rows: 100px;
              align-itens: center;
            }

Esse alinha no centro, nesse caso o conteúdo vai ficar no px 50;

Agora o justify itens é a mesma coisa, as propriedades são iguais, a diferença é que o justify alinha horizontalmente.

Vou colocar os valores de novo só pra falar que puz.

          
            .pai {
              display: grid;
              grid-template-columns: auto;
              grid-template-rows: 100px;
              justify-itens: start
              ou end
              ou center
              ou stretch (padrão)
            }

Lembrando que o alinhamento é da esquerda para a direita.

Agora vamos mecher com as propriedades de content.

Começando por align content:

O content é um conjunto de grid itens.

Ou seja, essa propriedade alinha o conjunto deles verticalmente.

Lembra do justify content lá do flex box? as propriedades dele são iguais em todos comandos que tem content no nome.

Ou seja, start, end, center, space-around, space-between e space-evenly.

Também tem o stretch, que tá aqui só pra marcar presença.

Esses são os 7 valores que o justify e o align content podem levar, acho que não preciso expliar cada um de novo então vou deixar só essa explicalção mesmo.

Grid-auto

Veremos 2 novas propriedades nesse tópico, grid-auto-column e grid-auto-row.

Ela é bem simples:

          
            .pai {
              display: grid;
              grid-auto-row: 100px;
              grid-auto-column: 100px;
            }

Quando usamos o grid template ele define uma linha ou coluna de cada vez, desse modo, teríaros que escrever a mesma onfiguração diversas vezes.

Já com essa propriedade isso não acontece.

Nesse caso, todas as colunas e linhas seriam 100x100px, independente da quantidade, a não ser que fizessemos a alteração manual, usando o templete.

Shorthands

O primeiro shorthand que eu vou mostrar é o place-itens, que configura o align-itens e o justify-itens:

          
            .pai {
              display: grid;
              grid-template-rows: 100px;
              grid-template-columns: 100px;
              place-itens: stretch center;
            }

            É o mesmo que:

            .pai {
              display: grid;
              grid-template-rows: 100px;
              grid-template-columns: 100px;  
              justify-itens: center;
              align-itens: stretch;
            }

Primeiro sempre o align depois o justify.

Seguindo a mesma lógica temos o place-content, que é auto explicativo:

          
            .pai {
              display: grid;
              grid-template-rows: 100px;
              grid-template-columns: 100px;
              place-content: space-between center;
            }

            É o mesmo que:

            .pai {
              display: grid;
              grid-template-rows: 100px;
              grid-template-columns: 100px; 
              justify-content: center;
              align-content: space-between;
            }

Também começa pelo align e depois vai pro justify.

O grid-template colums e rows também tem um shorthand, ele se chama grid-template:

          

             .pai {
              display: grid;
              grid-template: 100px 100px 100px / auto auto auto;
             }

             É o mesmo que:

            .pai {
              display: grid;
              grid-template-rows: 100px 100px 100px;
              grid-template-columns: auto auto auto; 
            }

Nesse aí o grid template rows vem antes do columns.

Repeat & Fração

Vou mostrar na prática o que é a função repeat():

          
            .pai {
              display: grid;
              grid-template: 100px 100px 100px/ auto auto auto;
            }

            É o mesmo que:

            .pai {
              display: grid;
              grid-template: repeat(3, 100px) / repeat(3, auto);
            }

Acho que deu pra entender mas eu vou explicar.

O primeiro parâmentro é quantas vezes o valor vai repetir, no caso é 3 vezes, o segundo parâmetro é qual valor vai repetir, no caso é o 100px e o auto.

Agora frações, elas são representadas por exemplo:

        
          .pai {
            display: grid;
            width: 200px;
            height: 200px;
            grid-template: 0.5fr 1.5fr / 0.5fr 1.5fr;
          }

Nesse caso a primeira linha e a primeira coluna vão ocupar 50px e a segunda linha e coluna vão ocupar 150px.

Seria como se estivessemos dividindo um bolo, o que ficou com 150px na teoria ficou com 3/4 do bolo, e o que ficou com 50px ficou com 1/4.

Você também pode misturar medidas, por exemplo fr, px, %, mas você não é maluco.

Auto-flow

Passando rapidinho nessa propriedade porque eu aprendi ela de última hora.

          
            .pai {
              display: grid;
              grid-template: 100px / 100px;
              grid-auto-rows: 100px;
              grid-auto-flow: row;
              (valor padrão)
            }

Essa propriedade tem 2 valores interessantes, row e column, ela define se a propriedade vai quebrar em linha ou coluna.

Nesse caso ela vai quebrar em linha e ainda vai manter os 100px naturalmente por conta do grid-auto-rows.
